# AnimRigPro

**Advanced Rigging System for Unreal Engine 5**

AnimRigPro brings Maya/Blender-level rigging capabilities to UE5 with full-body IK, FK chains, constraint systems, and procedural animation.

## Features

### Core Rigging Systems
- **FABRIK Solver** - Forward And Backward Reaching Inverse Kinematics for full-body IK
- **Two-Bone IK** - Optimized solver for arms and legs
- **Look-At IK** - Head tracking and aim constraints
- **FK Chain System** - Forward kinematics with hierarchical transforms

### Constraint System
- **Aim Constraint** - Orient bones to target positions
- **Parent Constraint** - Attach bones to multiple parents with weight blending
- **Position Constraint** - Lock bone positions to targets
- **Rotation Constraint** - Lock bone rotations with axis filtering
- **Scale Constraint** - Lock bone scales with weight blending
- **Pole Vector Constraint** - Control IK plane orientation

### Animation State Machine
- **IK/FK Blending** - Smooth transitions between IK and FK modes
- **Constraint Activation** - State-based constraint enable/disable
- **Blend Spaces** - Multi-dimensional animation blending
- **Transition Rules** - Condition-based state switching

### Editor Tools
- **Rig Editor** - Visual constraint setup and IK configuration
- **Constraint Inspector** - Real-time constraint weight adjustment
- **IK Settings Panel** - FABRIK iteration and tolerance controls
- **Bone Hierarchy Viewer** - Interactive skeleton tree

### Blueprint Integration
- 15+ Blueprint-callable methods for runtime control
- Dynamic constraint weight adjustment
- IK/FK mode switching
- Procedural bone manipulation

## Usage Example

```kain
actor MyCharacter:
    @component
    rig: RigComponent
    
    fn BeginPlay():
        # Setup IK chain for right arm
        let arm_chain = create_ik_chain(
            "shoulder_r",
            "hand_r",
            IKSolverType.FABRIK
        )
        rig.add_ik_chain(arm_chain)
        
        # Add aim constraint for head
        let aim = create_aim_constraint(
            "head",
            target_actor,
            1.0  # weight
        )
        rig.add_constraint(aim)
        
        # Enable IK mode
        rig.set_ik_mode(true)
    
    @blueprint_callable
    fn SetIKTarget(bone_name: String, target: Vec3):
        rig.set_ik_target(bone_name, target)
    
    @blueprint_callable
    fn BlendToFK(blend_time: Float):
        rig.blend_to_fk(blend_time)
```
