# 1.2 UE5 Runtime Features

> **Crate:** `ue5`  
> **Status:** Production — the largest single crate in the workspace  
> **Last Updated:** 2026-03-01

---

## Overview

The `ue5` crate is the primary UE5 backend. It generates production-quality UE5 C++ source (`.h` header + `.cpp` implementation) for actors, components, subsystems, replication, networking, async tasks, state machines, and Blueprint integration.

**Size:** 290KB main codegen + 70KB Oracle validator + 48KB stdlib resolver

---

## 1. Actor System

**Status:** ✅ Fully Implemented

### Description
KAIN `actor` constructs compile to `AActor` subclasses with full UE5 lifecycle integration.

### KAIN Syntax
```kain
actor Player:
    state health: Float = 100.0
    state max_health: Float = 100.0
    state position: Vec3 = vec3(0.0, 0.0, 0.0)
    
    fn take_damage(amount: Float):
        health = health - amount
        if health <= 0.0:
            die()
    
    fn die():
        println("Player died!")
```

### Generated UE5 C++
```cpp
UCLASS(HideCategories=(Input, Collision, LOD))
class MYPLUGIN_API APlayer : public AActor {
    GENERATED_BODY()
public:
    APlayer();
    
    UPROPERTY(EditAnywhere, BlueprintReadWrite, Category="Player")
    float Health = 100.0f;
    
    UPROPERTY(EditAnywhere, BlueprintReadWrite, Category="Player")
    float MaxHealth = 100.0f;
    
    UPROPERTY(EditAnywhere, BlueprintReadWrite, Category="Player")
    FVector Position = FVector(0.0f, 0.0f, 0.0f);
    
    virtual void BeginPlay() override;
    virtual void Tick(float DeltaTime) override;
    
    UFUNCTION(BlueprintCallable, Category="Player")
    void TakeDamage(float Amount);
    
    UFUNCTION(BlueprintCallable, Category="Player")
    void Die();
};
```

### Automatic Features
- `UCLASS()` with `HideCategories=(Input, Collision, LOD)` by default
- `GENERATED_BODY()` macro
- Constructor with `PrimaryActorTick.bCanEverTick = true`
- `BeginPlay()` and `Tick()` overrides
- `UPROPERTY(EditAnywhere, BlueprintReadWrite)` for state fields
- Automatic category assignment based on actor name

### Actor Attributes

| Attribute | Effect |
|-----------|--------|
| `@base("ACharacter")` | Custom base class (default `AActor`) |
| `@uclass("Blueprintable", "Abstract")` | Data-driven UCLASS specifiers |
| `@tick` | Enables tick function |
| `@beginplay` | Adds BeginPlay override |

### Component Auto-Creation
When actor has component-typed state fields:
- Auto-creates `USceneComponent` root component
- `CreateDefaultSubobject<T>()` for each component
- Automatic attachment to root

### Shader Resource Integration
When actor has shader fields:
- Double-buffered `UTextureRenderTarget2D*` resources (PositionRT_A/B, VelocityRT_A/B)
- Automatic initialization in `BeginPlay()`

### Factory Examples
- **VoxelForgePro** — `AVoxelGenerator` actor with 19 compute shaders
- **TacticalRaidGAS** — `AGameModeBase` actor with GAS integration
- **NarrativeGraph** — `ADialogueManager` actor coordinating dialogue state
- **Cinema4DMograph** — `AMographActor` with 20+ modifier components
- **FluidFlow** — `AFluidSimulator` actor with GPU compute integration

### Implementation Details
- **Codegen:** `codegen_ue5.rs` (290KB) — `generate_actor()`
- **Naming:** `ue5/naming.rs` (18KB) — `to_actor_name()` adds `A` prefix
- **Type Mapping:** `ue5/types.rs` (29KB) — KAIN types → UE5 C++ types
- **Post-Processing:** 5 fix passes (Replication, Shader, ForwardDecl, IncludeOrder, Formatting)

## 2. Component System

**Status:** ✅ Fully Implemented

### Description
`@component` structs compile to `UActorComponent` subclasses with full lifecycle support.

### KAIN Syntax
```kain
@component
struct HealthComponent:
    @replicated
    current: Float = 100.0
    @replicated
    max: Float = 100.0
    @savegame
    is_invulnerable: Bool = false
    
    @tick
    fn update(delta: Float):
        # Regenerate health over time
        if current < max:
            current = min(current + 5.0 * delta, max)
```

### Generated UE5 C++
```cpp
UCLASS(ClassGroup=(Custom), meta=(BlueprintSpawnableComponent))
class MYPLUGIN_API UHealthComponent : public UActorComponent {
    GENERATED_BODY()
public:
    UHealthComponent();
    
    UPROPERTY(Replicated, EditAnywhere, BlueprintReadWrite, Category="Health")
    float Current = 100.0f;
    
    UPROPERTY(Replicated, EditAnywhere, BlueprintReadWrite, Category="Health")
    float Max = 100.0f;
    
    UPROPERTY(SaveGame, EditAnywhere, BlueprintReadWrite, Category="Health")
    bool bIsInvulnerable = false;
    
    virtual void BeginPlay() override;
    virtual void TickComponent(float DeltaTime, ...) override;
    virtual void GetLifetimeReplicatedProps(TArray<FLifetimeProperty>& OutLifetimeProps) const override;
    
    void Update(float Delta);
};
```

### Automatic Features
- `UCLASS(ClassGroup=(Custom), meta=(BlueprintSpawnableComponent))`
- `SetIsReplicatedByDefault(true)` when `@replicated` fields present
- `GetLifetimeReplicatedProps()` with `DOREPLIFETIME` macros
- `BeginPlay()` override when `@beginplay` present
- `TickComponent()` override when `@tick` present

### Component Attributes

| Attribute | Effect |
|-----------|--------|
| `@component` | Marks struct as component |
| `@tick` | Enables TickComponent |
| `@beginplay` | Adds BeginPlay override |
| `@replicated` | Marks field for replication |
| `@savegame` | Marks field for save game serialization |
| `@transient` | Marks field as non-serialized |
| `@editdefaults` | EditDefaultsOnly instead of EditAnywhere |
| `@visibleonly` | VisibleAnywhere instead of EditAnywhere |

### Advanced Network Sync
```kain
@component
struct MovementComponent:
    @replicated(mode: "interpolated", back_time: 0.1)
    position: Vec3
    @replicated(mode: "interpolated", back_time: 0.1)
    velocity: Vec3
```

Generates:
- State buffers for interpolation/extrapolation
- Compression logic in TickComponent
- Automatic smoothing between network updates

### Factory Examples
- **TacticalRaidGAS** — `UAbilitySystemComponent` wrapper
- **FluidFlow** — `UFluidSimulationComponent` with GPU compute
- **Cinema4DMograph** — 20+ modifier components (Cloner, Effector, Deformer)
- **UESculpt** — `USculptComponent` with mesh manipulation
- **MetaFitter** — `UMetaHumanFitComponent` with bone mapping

### Implementation Details
- **Codegen:** `codegen_ue5.rs` — `generate_component()`
- **Naming:** `to_uobject_name()` adds `U` prefix + `Component` suffix
- **Replication:** `ReplicationFix` post-processor injects `GetLifetimeReplicatedProps`
- **Network Sync:** `network_sync_codegen.rs` (19KB) for advanced interpolation

## 4. RPC System (Server/Client/Multicast)

**Status:** ✅ Fully Implemented

### Description
Automatic RPC detection from handler name prefixes. No manual UFUNCTION specifiers needed.

### RPC Naming Convention

| Prefix | Generated UFUNCTION | Validation |
|--------|---------------------|------------|
| `Server_` | `UFUNCTION(Server, Reliable, WithValidation)` | Auto `_Validate()` method |
| `Client_` | `UFUNCTION(Client, Reliable)` | No validation |
| `Multicast_` | `UFUNCTION(NetMulticast, Reliable)` | No validation |

### KAIN Syntax
```kain
actor Player:
    state health: Float = 100.0
    
    on Server_TakeDamage(amount: Float):
        health = health - amount
        if health <= 0.0:
            Server_Die()
    
    on Server_Die():
        Multicast_PlayDeathEffect()
    
    on Multicast_PlayDeathEffect():
        println("Death effect!")
    
    on Client_ShowDamageIndicator(amount: Float):
        println("Took {amount} damage")
```

### Generated UE5 C++
```cpp
UFUNCTION(Server, Reliable, WithValidation)
void Server_TakeDamage(float Amount);
void Server_TakeDamage_Implementation(float Amount);
bool Server_TakeDamage_Validate(float Amount);

UFUNCTION(Server, Reliable, WithValidation)
void Server_Die();
void Server_Die_Implementation();
bool Server_Die_Validate();

UFUNCTION(NetMulticast, Reliable)
void Multicast_PlayDeathEffect();
void Multicast_PlayDeathEffect_Implementation();

UFUNCTION(Client, Reliable)
void Client_ShowDamageIndicator(float Amount);
void Client_ShowDamageIndicator_Implementation(float Amount);
```

### Automatic Features
- `_Implementation()` method for all RPCs
- `_Validate()` method for Server RPCs (returns `true` by default)
- Proper UFUNCTION specifiers based on prefix
- Oracle validation enforces naming convention

### Factory Examples
- **TacticalRaidGAS** — Server/Client RPCs for ability activation
- **FluidFlow** — Multicast RPCs for fluid simulation sync
- **NarrativeGraph** — Server RPCs for dialogue progression

### Implementation Details
- **Codegen:** `codegen_ue5.rs` — `generate_rpc_functions()`
- **Validation:** `ue5/oracle.rs` (70KB) — validates RPC naming convention
- **Naming:** Prefix detection in function name parsing

## 5. Replication System

**Status:** ✅ Fully Implemented

### Description
`@replicated` attribute marks fields for network replication. Automatic `GetLifetimeReplicatedProps` generation.

### KAIN Syntax
```kain
actor Player:
    @replicated
    health: Float = 100.0
    @replicated
    max_health: Float = 100.0
    @replicated
    team_id: Int = 0
    
    # Non-replicated local state
    last_damage_time: Float = 0.0
```

### Generated UE5 C++
```cpp
UCLASS()
class MYPLUGIN_API APlayer : public AActor {
    GENERATED_BODY()
public:
    APlayer() {
        bReplicates = true;
        // ...
    }
    
    UPROPERTY(Replicated, EditAnywhere, BlueprintReadWrite)
    float Health = 100.0f;
    
    UPROPERTY(Replicated, EditAnywhere, BlueprintReadWrite)
    float MaxHealth = 100.0f;
    
    UPROPERTY(Replicated, EditAnywhere, BlueprintReadWrite)
    int32 TeamId = 0;
    
    UPROPERTY(EditAnywhere, BlueprintReadWrite)
    float LastDamageTime = 0.0f;
    
    virtual void GetLifetimeReplicatedProps(TArray<FLifetimeProperty>& OutLifetimeProps) const override;
};

// In .cpp
void APlayer::GetLifetimeReplicatedProps(TArray<FLifetimeProperty>& OutLifetimeProps) const {
    Super::GetLifetimeReplicatedProps(OutLifetimeProps);
    DOREPLIFETIME(APlayer, Health);
    DOREPLIFETIME(APlayer, MaxHealth);
    DOREPLIFETIME(APlayer, TeamId);
}
```

### Automatic Features
- `bReplicates = true` in constructor when `@replicated` fields present
- `GetLifetimeReplicatedProps()` override
- `DOREPLIFETIME` macros for each replicated field
- `Replicated` UPROPERTY specifier

### Replication Modes

| Mode | KAIN Syntax | Effect |
|------|-------------|--------|
| Standard | `@replicated` | `DOREPLIFETIME` |
| Conditional | `@replicated(condition: "COND_OwnerOnly")` | `DOREPLIFETIME_CONDITION` |
| Interpolated | `@replicated(mode: "interpolated")` | State buffers + interpolation logic |

### Factory Examples
- **TacticalRaidGAS** — replicated ability state
- **FluidFlow** — replicated fluid simulation parameters
- **NarrativeGraph** — replicated dialogue state

### Implementation Details
- **Codegen:** `codegen_ue5.rs` — `generate_replication()`
- **Post-Processing:** `ReplicationFix` injects missing `GetLifetimeReplicatedProps`
- **Validation:** Oracle validates `@replicated` on non-replicating actors

## 6. Async Task System

**Status:** ✅ Fully Implemented

### Description
`@async_task` structs compile to `FRunnable` tasks with thread pool execution and game-thread callbacks.

### KAIN Syntax
```kain
@async_task
struct MeshGenerator:
    @input
    resolution: Int = 64
    @input
    seed: Int = 12345
    
    @output
    vertices: Array<Vec3> = []
    @output
    triangles: Array<Int> = []
    
    @callback(thread: "game")
    fn on_complete(result: MeshData):
        println("Mesh generation complete!")
```

### Generated UE5 C++
```cpp
class FMeshGeneratorTask : public FRunnable {
public:
    FMeshGeneratorTask(int32 InResolution, int32 InSeed);
    
    virtual uint32 Run() override;
    virtual void Stop() override;
    
    void OnComplete(const FMeshData& Result);
    
private:
    int32 Resolution;
    int32 Seed;
    TArray<FVector> Vertices;
    TArray<int32> Triangles;
    
    FRunnableThread* Thread;
    FThreadSafeBool bShouldStop;
};
```

### Automatic Features
- `FRunnable` base class
- `Run()` override for task execution
- `Stop()` override for cancellation
- Game-thread callback via `AsyncTask(ENamedThreads::GameThread, ...)`
- Thread pool management
- Priority support

### Async Task Attributes

| Attribute | Effect |
|-----------|--------|
| `@async_task` | Marks struct as async task |
| `@input` | Input parameter |
| `@output` | Output result |
| `@callback(thread: "game")` | Game-thread callback |
| `@callback(thread: "any")` | Any-thread callback |

### Factory Examples
- **VoxelForgePro** — async voxel chunk generation
- **UESculpt** — async mesh deformation
- **Cinema4DMograph** — async mograph calculation
- **MetaFitter** — async MetaHuman bone fitting

### Implementation Details
- **Codegen:** `async_task_codegen.rs` (25KB)
- **IR:** `async_task_ir.rs` (15KB)
- **Thread Pool:** Uses UE5 `FRunnableThread` + `FThreadManager`

enum class ECombatAnimationsState : uint8 {

## 8. Blueprint Integration

**Status:** ✅ Fully Implemented

### Description
Multiple Blueprint integration points: function libraries, Blueprint events, Blueprint-callable methods.

### Blueprint Function Libraries
```kain
@blueprint
fn calculate_damage(base: Float, multiplier: Float, armor: Float) -> Float:
    let raw = base * multiplier
    return max(raw * (1.0 - armor / 100.0), 0.0)
```

Generates:
```cpp
UCLASS()
class UMyPluginBlueprintLibrary : public UBlueprintFunctionLibrary {
    GENERATED_BODY()
public:
    UFUNCTION(BlueprintCallable, Category="MyPlugin")
    static float CalculateDamage(float Base, float Multiplier, float Armor);
};
```

### Blueprint Events
```kain
actor GameMode:
    @blueprint_event
    fn on_player_joined(player: Actor):
        println("Player joined!")
```

Generates:
```cpp
UFUNCTION(BlueprintNativeEvent, Category="GameMode")
void OnPlayerJoined(AActor* Player);
void OnPlayerJoined_Implementation(AActor* Player);
```

### Blueprint Method Attributes

| Attribute | UFUNCTION Specifier |
|-----------|---------------------|
| `@blueprint_callable` | `BlueprintCallable` |
| `@blueprint_pure` | `BlueprintPure` (adds `const`) |
| `@blueprint_event` | `BlueprintNativeEvent` + `_Implementation` |
| `@blueprint_implementable_event` | `BlueprintImplementableEvent` (no C++ body) |
| `@category("X")` | `Category="X"` |
| `@meta("ToolTip=...")` | `meta=(ToolTip="...")` |
| `@inline` | Body in header |
