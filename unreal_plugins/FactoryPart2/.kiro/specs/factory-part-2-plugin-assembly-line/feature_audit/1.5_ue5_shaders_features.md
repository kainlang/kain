# 1.5 UE5 Shaders Features

> **Crate:** `ue5-shaders`  
> **Status:** Production — the largest shader codebase in the UE5 suite  
> **Last Updated:** 2026-03-01

---

## Overview

The `ue5-shaders` crate generates UE5 Shader Format (`.usf`) code from KAIN `shader` items. Also generates the C++ `FGlobalShader` / `FMeshMaterialShader` subclasses, dispatch helpers, and POD mirror structs used to pass parameters from CPU to GPU.

**Size:** 189KB main USF codegen + 136KB validation + 30KB POD mirror + 19KB shader knowledge + 10KB type mapping

---

## 1. Compute Shader System

**Status:** ✅ Fully Implemented

### Description
`shader compute` constructs compile to `.usf` compute shaders with `[numthreads]` and C++ `FGlobalShader` dispatch wrappers.

### KAIN Syntax
```kain
shader compute VoxelGenerator(thread_id: Vec3):
    uniform grid_size: Int @0
    uniform noise_scale: Float @1
    uniform seed: Int @2
    buffer output: RWBuffer<Float> @3
    
    let pos = thread_id * noise_scale
    let noise = perlin_noise(pos + vec3(seed, seed, seed))
    output[thread_id.x + thread_id.y * grid_size + thread_id.z * grid_size * grid_size] = noise
```

### Generated USF Code
```hlsl
#include "Platform.ush"
#include "MyPluginCommon.ush"

// Scalar uniforms in constant buffer
cbuffer VoxelGeneratorConstants : register(b0) {
    int GridSize;
    float NoiseScale;
    int Seed;
};

// UAV buffer
RWStructuredBuffer<float> Output : register(u0);

[numthreads(8, 8, 8)]
void VoxelGenerator_CS(uint3 ThreadId : SV_DispatchThreadID) {
    float3 Pos = float3(ThreadId) * NoiseScale;
    float Noise = PerlinNoise(Pos + float3(Seed, Seed, Seed));
    
    int Index = ThreadId.x + ThreadId.y * GridSize + ThreadId.z * GridSize * GridSize;
    Output[Index] = Noise;
}
```

### Generated C++ Header
```cpp
class FVoxelGeneratorCS : public FGlobalShader {
    DECLARE_GLOBAL_SHADER(FVoxelGeneratorCS)
    SHADER_USE_PARAMETER_STRUCT(FVoxelGeneratorCS, FGlobalShader)
    
    BEGIN_SHADER_PARAMETER_STRUCT(FParameters, )
        SHADER_PARAMETER(int32, GridSize)
        SHADER_PARAMETER(float, NoiseScale)
        SHADER_PARAMETER(int32, Seed)
        SHADER_PARAMETER_UAV(RWStructuredBuffer<float>, Output)
    END_SHADER_PARAMETER_STRUCT()
    
    static bool ShouldCompilePermutation(const FGlobalShaderPermutationParameters& Parameters);
    static void ModifyCompilationEnvironment(const FGlobalShaderPermutationParameters& Parameters, FShaderCompilerEnvironment& OutEnvironment);
};

// Dispatch helper
void DispatchVoxelGeneratorCS(
    FRHICommandListImmediate& RHICmdList,
    int32 GridSize,
    float NoiseScale,
    int32 Seed,
    FRWBuffer& OutputBuffer
);
```

### Generated C++ Implementation
```cpp
IMPLEMENT_GLOBAL_SHADER(FVoxelGeneratorCS, "/Plugin/MyPlugin/Private/VoxelGenerator.usf", "VoxelGenerator_CS", SF_Compute);

bool FVoxelGeneratorCS::ShouldCompilePermutation(const FGlobalShaderPermutationParameters& Parameters) {
    return IsFeatureLevelSupported(Parameters.Platform, ERHIFeatureLevel::SM5);
}

void FVoxelGeneratorCS::ModifyCompilationEnvironment(const FGlobalShaderPermutationParameters& Parameters, FShaderCompilerEnvironment& OutEnvironment) {
    FGlobalShader::ModifyCompilationEnvironment(Parameters, OutEnvironment);
    OutEnvironment.SetDefine(TEXT("THREADGROUP_SIZE_X"), 8);
    OutEnvironment.SetDefine(TEXT("THREADGROUP_SIZE_Y"), 8);
    OutEnvironment.SetDefine(TEXT("THREADGROUP_SIZE_Z"), 8);
}

void DispatchVoxelGeneratorCS(
    FRHICommandListImmediate& RHICmdList,
    int32 GridSize,
    float NoiseScale,
    int32 Seed,
    FRWBuffer& OutputBuffer
) {
    TShaderMapRef<FVoxelGeneratorCS> ComputeShader(GetGlobalShaderMap(GMaxRHIFeatureLevel));
    
    FVoxelGeneratorCS::FParameters* Parameters = ComputeShader->AllocateAndSetParameters(RHICmdList);
    Parameters->GridSize = GridSize;
    Parameters->NoiseScale = NoiseScale;
    Parameters->Seed = Seed;
    Parameters->Output = OutputBuffer.UAV;
    
    FComputeShaderUtils::Dispatch(RHICmdList, ComputeShader, *Parameters, FIntVector(GridSize / 8, GridSize / 8, GridSize / 8));
}
```

### Compute Shader Features
- `[numthreads(X,Y,Z)]` auto-sized from thread group dimensions
- `FGlobalShader` subclass with parameter struct
- `IMPLEMENT_GLOBAL_SHADER` macro
- Dispatch helper with RDG resource transitions
- UAV writes for output buffers
- Constant buffer for scalar uniforms
- Structured buffer for array data

### Thread Group Size
- Default: `[numthreads(8, 8, 8)]` (512 threads)
- Validation: Max 1024 total threads (X × Y × Z ≤ 1024)
- Configurable via shader attributes

### Factory Examples
- **VoxelForgePro** — 19 compute shaders for voxel terrain generation (noise, erosion, caves, biomes)
- **FluidFlow** — 8 compute shaders for fluid simulation (advection, pressure, divergence)
- **Cinema4DMograph** — 5 compute shaders for mograph calculations (cloner, effector, deformer)
- **MetaHumanVAT** — 3 compute shaders for vertex animation texture generation

### Implementation Details
- **Codegen:** `codegen_usf.rs` (189KB) — `generate_compute_shader()`
- **Validation:** `validation.rs` (136KB) — thread group size validation
- **Type Mapping:** `type_mapping.rs` (10KB) — KAIN types → HLSL types

## 2. Fragment Shader System

**Status:** ✅ Fully Implemented

### Description
`shader fragment` constructs compile to pixel shaders with `FPSInput`/`FPSOutput` structures.

### KAIN Syntax
```kain
shader fragment ColorTint(uv: Vec2) -> Vec4:
    uniform base_color: Vec3 @0
    uniform albedo_map: Sampler2D @1
    uniform tint_strength: Float @2
    
    let tex_color = sample(albedo_map, uv).rgb
    let tinted = lerp(tex_color, tex_color * base_color, tint_strength)
    return vec4(tinted, 1.0)
```

### Generated USF Code
```hlsl
#include "Platform.ush"

cbuffer ColorTintConstants : register(b0) {
    float3 BaseColor;
    float TintStrength;
};

Texture2D AlbedoMap : register(t0);
SamplerState AlbedoMapSampler : register(s0);

struct FPSInput {
    float2 UV : TEXCOORD0;
};

struct FPSOutput {
    float4 Color : SV_Target0;
};

void ColorTint_PS(FPSInput Input, out FPSOutput Output) {
    float3 TexColor = AlbedoMap.Sample(AlbedoMapSampler, Input.UV).rgb;
    float3 Tinted = lerp(TexColor, TexColor * BaseColor, TintStrength);
    Output.Color = float4(Tinted, 1.0);
}
```

### Fragment Shader Features
- `FPSInput` with UV coordinates
- `FPSOutput` with color target
- Texture sampling with `Texture2D` + `SamplerState`
- Constant buffer for scalar uniforms
- Multiple render targets support

### Factory Examples
- **ToonShaderz** — 5 fragment shaders for toon rendering (outline, cel shading, rim lighting)
- **VoxelForgePro** — 2 fragment shaders for voxel visualization
- **Cinema4DMograph** — 3 fragment shaders for mograph rendering

### Implementation Details
- **Codegen:** `codegen_usf.rs` — `generate_fragment_shader()`

## 3. Vertex Shader System

**Status:** ✅ Fully Implemented

### Description
`shader vertex` constructs compile to vertex shaders with `FVSInput`/`FVSOutput` structures.

### KAIN Syntax
```kain
shader vertex WaveDeform(pos: Vec3, normal: Vec3, uv: Vec2) -> Vec4:
    uniform time: Float @0
    uniform wave_amplitude: Float @1
    uniform wave_frequency: Float @2
    
    let offset = sin(pos.x * wave_frequency + time) * wave_amplitude
    let deformed_pos = pos + normal * offset
    return vec4(deformed_pos, 1.0)
```

### Generated USF Code
```hlsl
#include "Platform.ush"

cbuffer WaveDeformConstants : register(b0) {
    float Time;
    float WaveAmplitude;
    float WaveFrequency;
};

struct FVSInput {
    float3 Position : ATTRIBUTE0;
    float3 Normal : ATTRIBUTE1;
    float2 UV : ATTRIBUTE2;
};

struct FVSOutput {
    float4 Position : SV_Position;
    float2 UV : TEXCOORD0;
};

void WaveDeform_VS(FVSInput Input, out FVSOutput Output) {
    float Offset = sin(Input.Position.x * WaveFrequency + Time) * WaveAmplitude;
    float3 DeformedPos = Input.Position + Input.Normal * Offset;
    Output.Position = float4(DeformedPos, 1.0);
    Output.UV = Input.UV;
}
```

### Vertex Shader Features
- `FVSInput` with position, normal, UV, tangent
- `FVSOutput` with transformed position
- Vertex deformation support
- Skinning support (bone matrices)

### Factory Examples
- **UESculpt** — vertex shader for mesh deformation preview
- **Cinema4DMograph** — vertex shader for mograph deformation
- **MetaHumanVAT** — vertex shader for vertex animation texture playback

### Implementation Details
- **Codegen:** `codegen_usf.rs` — `generate_vertex_shader()`

## 4. Surface Shader System

**Status:** ✅ Fully Implemented

### Description
`shader surface` constructs compile to material surface shaders with PBR inputs.

### KAIN Syntax
```kain
shader surface PBRGround:
    uniform albedo_map: Sampler2D @0
    uniform normal_map: Sampler2D @1
    uniform roughness_value: Float @2
    uniform metallic_value: Float @3
    
    base_color = sample(albedo_map, uv).rgb
    normal = unpack_normal(sample(normal_map, uv).rgb)
    roughness = roughness_value
    metallic = metallic_value
```

### Generated USF Code
```hlsl
#include "Platform.ush"

Texture2D AlbedoMap : register(t0);
SamplerState AlbedoMapSampler : register(s0);
Texture2D NormalMap : register(t1);
SamplerState NormalMapSampler : register(s1);

cbuffer PBRGroundConstants : register(b0) {
    float RoughnessValue;
    float MetallicValue;
};

struct FSurfaceInput {
    float2 UV : TEXCOORD0;
};

struct FSurfaceOutput {
    float3 BaseColor;
    float3 Normal;
    float Roughness;
    float Metallic;
};

void PBRGround_Surface(FSurfaceInput Input, out FSurfaceOutput Output) {
    Output.BaseColor = AlbedoMap.Sample(AlbedoMapSampler, Input.UV).rgb;
    Output.Normal = UnpackNormal(NormalMap.Sample(NormalMapSampler, Input.UV).rgb);
    Output.Roughness = RoughnessValue;
    Output.Metallic = MetallicValue;
}
```

### Surface Shader Features
- PBR material inputs (BaseColor, Normal, Roughness, Metallic, Specular, Emissive)
- Texture sampling with automatic UV
- Normal map unpacking
- Material parameter support

### Factory Examples
- **ToonShaderz** — surface shader for toon materials
- **VoxelForgePro** — surface shader for voxel materials
- **Cinema4DMograph** — surface shader for mograph materials

### Implementation Details
- **Codegen:** `codegen_usf.rs` — `generate_surface_shader()`

## 5. Shader Permutation System

**Status:** ✅ Fully Implemented

### Description
Compile-time shader branches via `CFG_*` / `ENABLE_*` prefixed uniforms. Zero runtime cost.

### KAIN Syntax
```kain
shader compute ParticleUpdate(thread_id: Vec3):
    uniform CFG_ENABLE_COLLISION: Bool @0
    uniform CFG_ENABLE_GRAVITY: Bool @1
    uniform delta_time: Float @2
    buffer particles: RWBuffer<Particle> @3
    
    let particle = particles[thread_id.x]
    
    if CFG_ENABLE_GRAVITY:
        particle.velocity.z -= 9.8 * delta_time
    
    if CFG_ENABLE_COLLISION:
        if particle.position.z < 0.0:
            particle.position.z = 0.0
            particle.velocity.z = 0.0
    
    particles[thread_id.x] = particle
```

### Generated USF Code
```hlsl
#include "Platform.ush"

cbuffer ParticleUpdateConstants : register(b0) {
    float DeltaTime;
};

RWStructuredBuffer<FParticle> Particles : register(u0);

// Permutation defines
#ifndef ENABLE_COLLISION
#define ENABLE_COLLISION 0
#endif

#ifndef ENABLE_GRAVITY
#define ENABLE_GRAVITY 0
#endif

[numthreads(64, 1, 1)]
void ParticleUpdate_CS(uint3 ThreadId : SV_DispatchThreadID) {
    FParticle Particle = Particles[ThreadId.x];
    
    #if ENABLE_GRAVITY
        Particle.Velocity.z -= 9.8 * DeltaTime;
    #endif
    
    #if ENABLE_COLLISION
        if (Particle.Position.z < 0.0) {
            Particle.Position.z = 0.0;
            Particle.Velocity.z = 0.0;
        }
    #endif
    
    Particles[ThreadId.x] = Particle;
}
```

### Generated C++ Permutation
```cpp
class FParticleUpdateCS : public FGlobalShader {
    DECLARE_GLOBAL_SHADER(FParticleUpdateCS)
    
    class FEnableCollisionDim : public FShaderPermutationBool {
        DECLARE_SHADER_PERMUTATION_BOOL("ENABLE_COLLISION");
    };
    
    class FEnableGravityDim : public FShaderPermutationBool {
        DECLARE_SHADER_PERMUTATION_BOOL("ENABLE_GRAVITY");
    };
    
    using FPermutationDomain = TShaderPermutationDomain<FEnableCollisionDim, FEnableGravityDim>;
    
    // 4 permutations: (collision off, gravity off), (collision on, gravity off), (collision off, gravity on), (collision on, gravity on)
};
```

### Permutation Features
- `CFG_*` / `ENABLE_*` prefix detection
- `SHADER_PERMUTATION_BOOL` generation
- Compile-time branch elimination
- Zero runtime cost
- Automatic permutation domain generation

### Factory Examples
- **VoxelForgePro** — 8 shader permutations for terrain features (caves, erosion, biomes)
- **FluidFlow** — 4 shader permutations for fluid simulation modes
- **Cinema4DMograph** — 6 shader permutations for modifier types

### Implementation Details
- **Codegen:** `codegen_usf.rs` — `generate_permutations()`
- **Validation:** `validation.rs` — permutation validation

## 6. Shared Shader Library System

**Status:** ✅ Fully Implemented

### Description
When a plugin has >1 shader, a `{Plugin}Common.ush` is auto-generated containing shared math helpers.

### Generated Common.ush
```hlsl
// MyPluginCommon.ush
#pragma once

// Bounds checking
bool IsInBounds(float3 Pos, float3 Bounds) {
    return all(Pos >= 0.0) && all(Pos < Bounds);
}

// Pixel to UV conversion
float2 PixelToUV(float2 Pixel, float2 TexSize) {
    return (Pixel + 0.5) / TexSize;
}

// Hash noise
float HashNoise(float3 Pos) {
    float3 P = frac(Pos * 0.3183099 + 0.1);
    P *= 17.0;
    return frac(P.x * P.y * P.z * (P.x + P.y + P.z));
}

// Grayscale conversion
float Grayscale(float3 Color) {
    return dot(Color, float3(0.299, 0.587, 0.114));
}

// Perlin noise (if used by multiple shaders)
float PerlinNoise(float3 Pos) {
    // Implementation...
}
```

### Shared Library Features
- Auto-generated when plugin has >1 shader
- Conditional guard against duplicate assert
- Shared math helpers (IsInBounds, PixelToUV, HashNoise, Grayscale)
- Shared noise functions (Perlin, Simplex, Worley)
- Shared color functions (RGB to HSV, color grading)

### Factory Examples

- **FluidFlow** — `FluidFlowCommon.ush` with 8 shaders sharing fluid math

## 7. Uniform Classification System

**Status:** ✅ Fully Implemented

### Description
Shader uniforms are split into two output types: texture uniforms and scalar uniforms.

### Texture Uniforms
```hlsl
Texture2D AlbedoMap : register(t0);
SamplerState AlbedoMapSampler : register(s0);
Texture2D NormalMap : register(t1);
SamplerState NormalMapSampler : register(s1);
```

Textures are excluded from dispatch signature (bound separately via RHI).

### Scalar Uniforms
```hlsl
cbuffer ShaderConstants : register(b0) {
    float Time;
    float3 BaseColor;
    int GridSize;
    float NoiseScale;
};
```

Scalars are packed into constant buffer.

### Uniform Types

| KAIN Type | HLSL Type | Category |
|-----------|-----------|----------|
| `Sampler2D` | `Texture2D` + `SamplerState` | Texture |
| `RWTexture2D` | `RWTexture2D<float4>` | Texture (UAV) |
| `Buffer<T>` | `StructuredBuffer<T>` | Texture (SRV) |
| `RWBuffer<T>` | `RWStructuredBuffer<T>` | Texture (UAV) |
| `Float` | `float` | Scalar |
| `Vec2/3/4` | `float2/3/4` | Scalar |
| `Int` | `int` | Scalar |
| `Bool` | `bool` | Scalar |
| `Mat4` | `float4x4` | Scalar |

### Factory Examples
- **All shader plugins** — uniform classification used throughout

### Implementation Details
- **Type Mapping:** `type_mapping.rs` (10KB) — `classify_uniform()`
- **Codegen:** `codegen_usf.rs` — separate texture and scalar generation

## 8. POD Mirror Struct System

**Status:** ✅ Fully Implemented

### Description
For compute shaders that read from CPU-side data, POD mirror structs are generated for GPU buffer upload.

### KAIN Struct
```kain
struct ParticleData:
    position: Vec3
    velocity: Vec3
    lifetime: Float
    flags: Int
```

### Generated POD Mirror
```cpp
// Generated POD mirror for GPU upload
struct FParticleData_GPUMirror {
    FVector3f Position;   // float3 packed
    FVector3f Velocity;   // float3 packed
    float Lifetime;       // float scalar
    uint32 Flags;         // uint bitfield
};

static_assert(sizeof(FParticleData_GPUMirror) % 16 == 0, "Must be 16-byte aligned for GPU buffer upload");
static_assert(offsetof(FParticleData_GPUMirror, Position) == 0, "Position must be at offset 0");
static_assert(offsetof(FParticleData_GPUMirror, Velocity) == 12, "Velocity must be at offset 12");
```

### POD Mirror Features
- 16-byte alignment for GPU buffer upload
- Field order matches KAIN struct declaration order
- No non-POD members (no virtuals, no strings)
- Automatic padding insertion
- Static assertions for layout validation

### Factory Examples
- **VoxelForgePro** — POD mirrors for voxel data structures
- **FluidFlow** — POD mirrors for fluid particle data
- **Cinema4DMograph** — POD mirrors for mograph instance data

### Implementation Details
- **Codegen:** `pod_mirror.rs` (30KB)
- **Validation:** POD validation (no virtuals, no strings)

## 9. Shader Validation System

**Status:** ✅ Fully Implemented

### Description
Pre-codegen shader validation catches errors before UE5 compilation.

### Validation Checks

| Check | Rule |
|-------|------|
| Thread group size | Max 1024 total threads (X × Y × Z ≤ 1024) |
| Binding slot uniqueness | Duplicate `@slot` assignments flagged |
| UAV type consistency | `RWTexture2D` and `RWBuffer` cannot share slot with SRV |
| POD struct validation | Shader parameter structs must be plain data (no virtuals, no strings) |
| Conditional shader directory mapping | Duplicate file path assertions |
| Type compatibility | Shader input/output types must match HLSL semantic |
| Texture coordinate normalization | UV coordinates must be in [0, 1] range |
| Simulation texture point sampling | `Load()` instead of `Sample()` for simulation textures |

### Factory Examples
- **All shader plugins** — validation used before codegen

### Implementation Details
- **Validation:** `validation.rs` (136KB)
- **Type Mapping:** `type_mapping.rs` (10KB) — unified KAIN→HLSL type mappings

## Summary

The `ue5-shaders` crate provides 10 major shader feature categories:

1. ✅ Compute Shader System ([numthreads], FGlobalShader, dispatch helpers)
2. ✅ Fragment Shader System (pixel shaders with FPSInput/FPSOutput)
3. ✅ Vertex Shader System (vertex shaders with FVSInput/FVSOutput)
4. ✅ Surface Shader System (PBR material shaders)
5. ✅ Shader Permutation System (CFG_*/ENABLE_* compile-time branches)
6. ✅ Shared Shader Library System ({Plugin}Common.ush auto-generation)
7. ✅ Uniform Classification System (texture vs scalar uniforms)
8. ✅ POD Mirror Struct System (GPU buffer upload structs)
9. ✅ Shader Validation System (pre-codegen error detection)
10. ✅ Shader Knowledge System (data-driven metadata)

All features are production-ready and tested across VoxelForgePro (19 shaders), FluidFlow (8 shaders), Cinema4DMograph (5 shaders), and other Factory plugins.
