# 1.3 UE5 Editor Features

> **Crate:** `ue5-editor`  
> **Status:** Production — Slate, Details, Viewport, Toolbar, Asset Editors all implemented  
> **Last Updated:** 2026-03-01

---

## Overview

The `ue5-editor` crate generates UE5 editor extension C++ from KAIN editor constructs. Covers the full range of UE5 editor customization from simple Details panel customizations to full custom Asset Editors with toolbars and viewports.

**Size:** 120KB Slate codegen + 48KB Details codegen + 55KB main orchestrator

## 1. Slate Widget System

**Status:** ✅ Fully Implemented

### Description
`@slate` structs compile to `SCompoundWidget` subclasses with full Slate declarative UI support.

### KAIN Syntax
```kain
@slate
struct MyWidget:
    label: String = "Hello"
    on_clicked: Callback = null
    
    fn construct():
        return vertical_box([
            text_block(label),
            button("Click Me", on_clicked)
        ])
```

### Generated UE5 C++
```cpp
class SMyWidget : public SCompoundWidget {
public:
    SLATE_BEGIN_ARGS(SMyWidget) {}
        SLATE_ATTRIBUTE(FText, Label)
        SLATE_EVENT(FSimpleDelegate, OnClicked)
    SLATE_END_ARGS()
    
    void Construct(const FArguments& InArgs);
    
private:
    TAttribute<FText> Label;
    FSimpleDelegate OnClicked;
};

void SMyWidget::Construct(const FArguments& InArgs) {
    Label = InArgs._Label;
    OnClicked = InArgs._OnClicked;
    
    ChildSlot
    [
        SNew(SVerticalBox)
        + SVerticalBox::Slot()
          .AutoHeight()
        [
            SNew(STextBlock)
            .Text(Label)
        ]
        + SVerticalBox::Slot()
          .AutoHeight()
        [
            SNew(SButton)
            .Text(LOCTEXT("ClickMe", "Click Me"))
            .OnClicked_Lambda([this]() {
                OnClicked.ExecuteIfBound();
                return FReply::Handled();
            })
        ]
    ];
}
```

### Supported Widget Types

| KAIN Widget | Slate Class | Purpose |
|-------------|-------------|---------|
| `text_block(text)` | `STextBlock` | Static text display |
| `button(label, callback)` | `SButton` | Clickable button |
| `check_box(checked, callback)` | `SCheckBox` | Toggle checkbox |
| `spinner(value, min, max)` | `SSpinBox<float>` | Numeric input |
| `list_view(items)` | `SListView<UObject*>` | Scrollable list |
| `tree_view(items)` | `STreeView<UObject*>` | Hierarchical tree |
| `tab_stack(tabs)` | `SDockTab` + `FTabManager` | Tabbed interface |
| `splitter(children)` | `SSplitter` | Resizable split |
| `horizontal_box(children)` | `SHorizontalBox` | Horizontal layout |
| `vertical_box(children)` | `SVerticalBox` | Vertical layout |
| `box(child)` | `SBox` | Single child container |
| `overlay(children)` | `SOverlay` | Layered children |
| `border(child)` | `SBorder` | Border decoration |
| `scroll_box(children)` | `SScrollBox` | Scrollable container |
| `image(path)` | `SImage` | Image display |
| `combo_box(items)` | `SComboBox<TSharedPtr<FString>>` | Dropdown selection |
| `edit_text(text, callback)` | `SEditableTextBox` | Text input |

### Slate Build Pattern
Generated code uses the chained fluent Slate API:
```cpp
SNew(SVerticalBox)
+ SVerticalBox::Slot()
  .AutoHeight()
  .Padding(4.0f)
[
    SNew(STextBlock)
    .Text(LOCTEXT("Label", "My Widget"))
]
```

### SLATE_BEGIN_ARGS Generation
For `@slate struct` types:
```cpp
SLATE_BEGIN_ARGS(SMyWidget) {}
    SLATE_ATTRIBUTE(FText, Label)
    SLATE_EVENT(FSimpleDelegate, OnClicked)
SLATE_END_ARGS()
```

## 2. Details Panel System

**Status:** ✅ Fully Implemented

### Description
`@details` structs compile to `IDetailCustomization` subclasses with property binding via `IPropertyHandle`.

### KAIN Syntax
```kain
@details
struct CombatDetails:
    @slider(min: 0.0, max: 1000.0)
    health: Float
    
    @slider(min: 0.0, max: 100.0)
    armor: Float
    
    @color_picker
    team_color: Color
    
    @button(label: "Reset Stats")
    fn reset_stats():
        health = 100.0
        armor = 0.0
```

### Generated UE5 C++
```cpp
class FCombatDetailsCustomization : public IDetailCustomization {
public:
    static TSharedRef<IDetailCustomization> MakeInstance();
    virtual void CustomizeDetails(IDetailLayoutBuilder& DetailBuilder) override;
    
private:
    TSharedPtr<IPropertyHandle> HealthProperty;
    TSharedPtr<IPropertyHandle> ArmorProperty;
    TSharedPtr<IPropertyHandle> TeamColorProperty;
    
    float GetHealthValue() const;
    void SetHealthValue(float Value);
    FReply OnResetStatsClicked();
};

void FCombatDetailsCustomization::CustomizeDetails(IDetailLayoutBuilder& DetailBuilder) {
    HealthProperty = DetailBuilder.GetProperty(GET_MEMBER_NAME_CHECKED(UCombatComponent, Health));
    ArmorProperty = DetailBuilder.GetProperty(GET_MEMBER_NAME_CHECKED(UCombatComponent, Armor));
    TeamColorProperty = DetailBuilder.GetProperty(GET_MEMBER_NAME_CHECKED(UCombatComponent, TeamColor));
    
    IDetailCategoryBuilder& CombatCategory = DetailBuilder.EditCategory("Combat");
    
    // Health slider
    CombatCategory.AddCustomRow(LOCTEXT("Health", "Health"))
        .NameContent()
        [
            HealthProperty->CreatePropertyNameWidget()
        ]
        .ValueContent()
        [
            SNew(SSpinBox<float>)
            .MinValue(0.0f)
            .MaxValue(1000.0f)
            .Value_Lambda([this]() { return GetHealthValue(); })
            .OnValueChanged_Lambda([this](float Val) { SetHealthValue(Val); })
        ];
    
    // Armor slider
    CombatCategory.AddCustomRow(LOCTEXT("Armor", "Armor"))
        .NameContent()
        [
            ArmorProperty->CreatePropertyNameWidget()
        ]
        .ValueContent()
        [
            SNew(SSpinBox<float>)
            .MinValue(0.0f)
            .MaxValue(100.0f)
            .Value_Lambda([this]() { return GetArmorValue(); })
            .OnValueChanged_Lambda([this](float Val) { SetArmorValue(Val); })
        ];
    
    // Team color picker
    CombatCategory.AddCustomRow(LOCTEXT("TeamColor", "Team Color"))
        .NameContent()
        [
            TeamColorProperty->CreatePropertyNameWidget()
        ]
        .ValueContent()
        [
            SNew(SColorBlock)
            .Color_Lambda([this]() { return GetTeamColorValue(); })
            .OnMouseButtonDown_Lambda([this](const FGeometry&, const FPointerEvent&) {
                // Open color picker modal
                return FReply::Handled();
            })
        ];
    
    // Reset button
    CombatCategory.AddCustomRow(LOCTEXT("ResetStats", "Reset Stats"))
        .WholeRowContent()
        [
            SNew(SButton)
            .Text(LOCTEXT("ResetStatsButton", "Reset Stats"))
            .OnClicked_Lambda([this]() { return OnResetStatsClicked(); })
        ];
}
```

### Details Panel Attributes

| Attribute | Generated Widget | Description |
|-----------|------------------|-------------|
| `@slider(min, max)` | `SSpinBox<float>` | Numeric slider with range |
| `@color_picker` | `SColorBlock` | Color picker modal |
| `@button(label)` | `SButton` | Clickable button |
| (object ref fields) | `SObjectPropertyEntryBox` | Object reference picker |
| (default) | Property widget | Default property widget |

### Property Binding
Uses `GET_MEMBER_NAME_CHECKED` macro for type-safe property name binding:
```cpp
HealthProperty = DetailBuilder.GetProperty(GET_MEMBER_NAME_CHECKED(UCombatComponent, Health));
```

Auto-generates `Value_Lambda` and `OnValueChanged_Lambda` for each property binding:
```cpp
.Value_Lambda([this]() { return GetHealthValue(); })
.OnValueChanged_Lambda([this](float Val) { SetHealthValue(Val); })
```

## 4. Toolbar System

**Status:** ✅ Fully Implemented

### Description
`@toolbar` attributes generate `FToolBarBuilder` with buttons, toggles, separators, and dropdowns.

### KAIN Syntax
```kain
@toolbar
struct EditorToolbar:
    @button(label: "Generate")
    fn on_generate():
        println("Generate clicked")
    
    @toggle(label: "Auto Update")
    fn on_auto_update_toggled(enabled: Bool):
        println("Auto update: {enabled}")
    
    @separator
    
    @dropdown(label: "Presets")
    fn on_preset_selected(preset: String):
        println("Preset: {preset}")
```

### Generated UE5 C++
```cpp
void FEditorToolbarBuilder::BuildToolbar(FToolBarBuilder& ToolbarBuilder) {
    ToolbarBuilder.BeginSection("EditorToolbar");
    
    // Generate button
    ToolbarBuilder.AddToolBarButton(
        FUIAction(
            FExecuteAction::CreateLambda([]() {
                // OnGenerate logic
            })
        ),
        NAME_None,
        LOCTEXT("Generate", "Generate"),
        LOCTEXT("GenerateTooltip", "Generate"),
        FSlateIcon()
    );
    
    // Auto Update toggle
    ToolbarBuilder.AddToolBarButton(
        FUIAction(
            FExecuteAction::CreateLambda([]() {
                // Toggle logic
            }),
            FCanExecuteAction(),
            FIsActionChecked::CreateLambda([]() {
                return bAutoUpdate;
            })
        ),
        NAME_None,
        LOCTEXT("AutoUpdate", "Auto Update"),
        LOCTEXT("AutoUpdateTooltip", "Auto Update"),
        FSlateIcon(),
        EUserInterfaceActionType::ToggleButton
    );
    
    // Separator
    ToolbarBuilder.AddSeparator();
    
    // Presets dropdown
    ToolbarBuilder.AddComboButton(
        FUIAction(),
        FOnGetContent::CreateLambda([]() {
            // Dropdown menu content
            return SNullWidget::NullWidget;
        }),
        LOCTEXT("Presets", "Presets"),
        LOCTEXT("PresetsTooltip", "Presets"),
        FSlateIcon()
    );
    
    ToolbarBuilder.EndSection();
}
```

### Toolbar Attributes

| Attribute | Generated Item |
|-----------|----------------|
| `@button(label)` | `AddToolBarButton` |
| `@toggle(label)` | `AddToolBarButton` with `IsChecked` binding |
| `@separator` | `AddSeparator` |
| `@dropdown(label)` | `AddComboButton` |

## 5. Asset Editor System

**Status:** ✅ Fully Implemented

### Description
`@asset_editor` structs compile to full `FAssetEditorToolkit` with viewport + details + toolbar.

### KAIN Syntax
```kain
@asset_editor
struct DialogueEditor:
    @viewport
    preview: DialoguePreview
    
    @details
    properties: DialogueProperties
    
    @toolbar
    toolbar: DialogueToolbar
```

### Generated UE5 C++
```cpp
class FDialogueEditor : public FAssetEditorToolkit {
public:
    void InitEditor(const TArray<UObject*>& InObjects);
    
    virtual void RegisterTabSpawners(const TSharedRef<FTabManager>& InTabManager) override;
    virtual void UnregisterTabSpawners(const TSharedRef<FTabManager>& InTabManager) override;
    
    virtual FName GetToolkitFName() const override;
    virtual FText GetBaseToolkitName() const override;
    virtual FString GetWorldCentricTabPrefix() const override;
    virtual FLinearColor GetWorldCentricTabColorScale() const override;
    
private:
    TSharedRef<SDockTab> SpawnViewportTab(const FSpawnTabArgs& Args);
    TSharedRef<SDockTab> SpawnDetailsTab(const FSpawnTabArgs& Args);
    
    TSharedPtr<SDialoguePreviewViewport> ViewportWidget;
    TSharedPtr<IDetailsView> DetailsView;
};

void FDialogueEditor::RegisterTabSpawners(const TSharedRef<FTabManager>& InTabManager) {
    FAssetEditorToolkit::RegisterTabSpawners(InTabManager);
    
    InTabManager->RegisterTabSpawner("ViewportTab", FOnSpawnTab::CreateSP(this, &FDialogueEditor::SpawnViewportTab))
        .SetDisplayName(LOCTEXT("ViewportTab", "Viewport"))
        .SetGroup(WorkspaceMenuCategory.ToSharedRef());
    
    InTabManager->RegisterTabSpawner("DetailsTab", FOnSpawnTab::CreateSP(this, &FDialogueEditor::SpawnDetailsTab))
        .SetDisplayName(LOCTEXT("DetailsTab", "Details"))
        .SetGroup(WorkspaceMenuCategory.ToSharedRef());
}
```

- Tab spawner registration via `FTabManager::FLayout`
- Default docking layout combining Viewport + Details + Toolbar
- `RegisterTabSpawners` / `UnregisterTabSpawners`

## 6. Editor Module System

**Status:** ✅ Fully Implemented

### Description
`@editor_module` structs compile to `IModuleInterface` with menu entries and toolbar buttons.

### KAIN Syntax
```kain
@editor_module
struct MyEditorModule:
    @menu_entry(path: "Window", label: "My Tool")
    fn open_my_tool():
        println("Opening my tool")
    
    @toolbar_button(section: "Tools", icon: "MyIcon")
    fn quick_action():
        println("Quick action")
```

### Generated UE5 C++
```cpp
class FMyEditorModule : public IModuleInterface {
public:
    virtual void StartupModule() override;
    virtual void ShutdownModule() override;
    
private:
    void RegisterMenus();
    void OnOpenMyTool();
    void OnQuickAction();
    
    TSharedPtr<FUICommandList> CommandList;
};

void FMyEditorModule::StartupModule() {
    RegisterMenus();
}

void FMyEditorModule::RegisterMenus() {
    FLevelEditorModule& LevelEditorModule = FModuleManager::LoadModuleChecked<FLevelEditorModule>("LevelEditor");
    
    // Menu entry
    TSharedPtr<FExtender> MenuExtender = MakeShareable(new FExtender());
    MenuExtender->AddMenuExtension(
        "Window",
        EExtensionHook::After,
        CommandList,
        FMenuExtensionDelegate::CreateRaw(this, &FMyEditorModule::AddMenuEntry)
    );
    LevelEditorModule.GetMenuExtensibilityManager()->AddExtender(MenuExtender);
    
    // Toolbar button
    TSharedPtr<FExtender> ToolbarExtender = MakeShareable(new FExtender());
    ToolbarExtender->AddToolBarExtension(
        "Tools",
        EExtensionHook::After,
        CommandList,
        FToolBarExtensionDelegate::CreateRaw(this, &FMyEditorModule::AddToolbarButton)
    );
    LevelEditorModule.GetToolBarExtensibilityManager()->AddExtender(ToolbarExtender);
}

IMPLEMENT_MODULE(FMyEditorModule, MyEditorModule)
```

### Editor Module Attributes

| Attribute | Effect |
|-----------|--------|
| `@editor_module` | Marks struct as editor module |
| `@menu_entry(path, label)` | Adds menu item to Level Editor |
| `@toolbar_button(section, icon)` | Adds button to Level Editor toolbar |

### Automatic Features
- `IModuleInterface` base class
- `StartupModule()` / `ShutdownModule()` lifecycle
- `IMPLEMENT_MODULE` macro
- Menu extensibility via `FExtender`
- Toolbar extensibility via `FExtender`
- `FTSTicker` registration for periodic editor tick callbacks

- **UESculpt** — editor module with sculpting tool menu entry
- **Cinema4DMograph** — editor module with mograph editor menu entry
- **NarrativeGraph** — editor module with dialogue editor menu entry

### Implementation Details
- **Codegen:** `editor/editor_module_codegen.rs` (21KB)
