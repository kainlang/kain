# 3D Smokes

These smokes focus on Kain as the authoring layer for 3D workflows, viewport tooling, and DCC-facing prototypes.

Included:

- `sculpt_foundry_prototype`: Kain-authored sculpt-suite prototype with a local Rust crate backend for stroke and mesh forecasting
- `native_sculpt_runtime`: Kain-authored sculpt session over a Rust backend crate and a C-native Win32 viewport host
