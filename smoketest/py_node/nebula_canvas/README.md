# Nebula Canvas Smoke

This smoke proves Kain can run Python and Node from the same `.kn` file.

Roles:

- Python: generates orbital point data with NumPy
- Kain: composes the SVG scene and runtime report
- Node: packages document/image payloads and writes the final web artifacts

Run:

```powershell
run_all.bat
run_test.bat
run_interpret.bat
```

Artifacts:

- `outputs/nebula_canvas.html`
- `outputs/nebula_canvas.svg`
- `outputs/nebula_canvas_report.txt`
