# Python + Cargo + Node + C Smokes

These smokes prove Kain can drive Python, Rust crate FFI, Node, and C from one `.kn` file while keeping shared payloads on the neutral interop contract.

Included:

- `quad_prism_halo`: visual shared-image smoke where Python generates the base raster, Kain paints an overlay, Rust computes signatures, C mutates the same image in place, and Node emits the viewer and image artifacts
