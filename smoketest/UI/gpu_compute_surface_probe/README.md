# GPU Compute Surface Probe Smoke

This smoke is the smallest UI/native probe for the new compute pipeline.

It deliberately combines:

- a semantic UI surface with `viewport3d`
- an authored `shader compute` item
- explicit `comptime` compute-plan metadata
- native app packaging that should stage shader, residency, and GPU runtime artifacts together

Run:

```powershell
run_all.bat
build_native_exe.bat
launch_native_exe.bat
cargo run -q -p cli --bin kain -- smoketest/UI/gpu_compute_surface_probe/smoke.kn -t test
cargo run -q -p cli --bin kain -- smoketest/UI/gpu_compute_surface_probe/smoke.kn -t interpret
```

## Output Hygiene

- `native-app/` is generated by the build scripts and can be deleted between runs.
- Remove `native-app/target/` and compiled `.exe`/`.dll` outputs after validation.

Expected native packaging artifacts inside `native-app/generated`:

- `kain_shader_bundle.json`
- `kain_compute_residency.json`
- `kain_compute_residency_*.bin`
- `kain_gpu_runtime.dll` beside the built executable
