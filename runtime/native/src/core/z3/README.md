# Kain Core Z3 Proof Pack

This is the durable Z3 proof workspace for Kain-owned language/runtime invariants.

Use this pack for small, sharp proof obligations that future agents should be able to rerun without rediscovering the model:

- actor mailbox count and bounded-queue invariants
- scheduler queue-depth accounting
- actor ID and sentinel invariants
- supervision restart-limit arithmetic
- low-level native runtime arithmetic that protects Kain ABI contracts

The pack intentionally lives under `src/core/z3` because `src/core` is the owned selfhost language root, while many first proofs point at `runtime/native/src/core` as the current executable substrate. Treat runtime/native proofs here as bridge proofs for Kain-owned semantics, not as permission to move language truth into C.

Common commands:

```powershell
uv run --project C:\Dev\polytools\z3-mcp --no-sync z3-mcp-batch --pack-path D:\Kain-Lang\src\core --lane smoke
uv run --project C:\Dev\polytools\z3-mcp --no-sync z3-mcp-batch --pack-path D:\Kain-Lang\src\core --lane actor
uv run --project C:\Dev\polytools\z3-mcp --no-sync z3-mcp-batch --workspace --project-root D:\Kain-Lang --lane smoke
```

Pack layout:

- `z3.toml` defines lanes, source scope, templates, fixtures, and report location.
- `proofs/` holds solver-runnable YAML proof cases.
- `templates/` holds local matcher/spec templates for future extraction.
- `reports/` is generated by proof runs and should be treated as validation output.
- `generated/` is for counterexample-to-test outputs or other proof-derived artifacts.
