## 1. Architecture

Single-file `backends/x11/host_x11.c` implementing the 4-function `KaintanaBackendVTable`:

```c
const KaintanaBackendVTable kaintana_x11_backend = {
    .init      = x11_init,
    .shutdown  = x11_shutdown,
    .new_frame = x11_new_frame,
    .render    = x11_render
};
```

**Pattern:** Identical to `host_win32.c` — static globals for display, window, GC, pixmap, input state. No complex state machine. No GPU pipeline. Pure Xlib software rendering.

**Included headers:**

```c
#include <X11/Xlib.h>
#include <X11/Xatom.h>
#include <X11/Xutil.h>
#include <X11/Xresource.h>   // For Xft.dpi

#include <X11/cursorfont.h>  // Standard cursors
#include "../../kaintana.h"
#include <stdint.h>
#include <stdbool.h>
#include <string.h>
#include <stdio.h>
#include <stdlib.h>
```

**Zero platform deps in core.** `host_x11.c` is the only file that sees `<X11/Xlib.h>`.

```c
    g_screen = DefaultScreen(g_display);
```

### 3.2 Window Creation

```c
static int x11_create_window(const KaintanaBackendConfig* config) {
    Window root = RootWindow(g_display, g_screen);
    int w = (config->width  > 0) ? config->width  : 800;
    int h = (config->height > 0) ? config->height : 600;
    
    XSetWindowAttributes attrs = {0};
    attrs.event_mask = ExposureMask | StructureNotifyMask
                     | ButtonPressMask | ButtonReleaseMask
                     | PointerMotionMask | KeyPressMask | KeyReleaseMask
                     | FocusChangeMask | EnterWindowMask | LeaveWindowMask;
    attrs.background_pixel = 0;     // Black background, no flash
    
    g_window = XCreateWindow(g_display, root,
        0, 0, w, h, 0,
        CopyFromParent, InputOutput, CopyFromParent,
        CWEventMask | CWBackPixel, &attrs);
    
    // Set title
    const char* title = config->title ? config->title : "Kaintana";
    XStoreName(g_display, g_window, title);
    
    // Set _NET_WM_NAME for modern WMs (UTF-8)
    g_net_wm_name = XInternAtom(g_display, "_NET_WM_NAME", False);
    XChangeProperty(g_display, g_window, g_net_wm_name,
        XInternAtom(g_display, "UTF8_STRING", False), 8,
        PropModeReplace, (unsigned char*)title, strlen(title));
    
    // WM_DELETE_WINDOW protocol
    g_wm_delete_window = XInternAtom(g_display, "WM_DELETE_WINDOW", False);
    XSetWMProtocols(g_display, g_window, &g_wm_delete_window, 1);
    
    // Create GC
    g_gc = XCreateGC(g_display, g_window, 0, NULL);
    
    // Show
    XMapWindow(g_display, g_window);
    XFlush(g_display);
    
    g_win_width  = w;
    g_win_height = h;
    g_is_open    = true;
    return 0;
}
```

### 3.3 Atoms Required

| Atom | Purpose |
|------|---------|
| `WM_DELETE_WINDOW` | Close button → `g_should_close = true` |
| `_NET_WM_NAME` | UTF-8 title (modern WMs) |
| `WM_PROTOCOLS` | Protocol atom for WM_DELETE_WINDOW |
| `CLIPBOARD` | X11 clipboard selection |
| `PRIMARY` | X11 primary selection |
| `TARGETS` | Clipboard format negotiation |
| `UTF8_STRING` | UTF-8 clipboard data |

## 4. Message Loop

### 4.1 `x11_new_frame()` — Pump and Bridge

```c
static void x11_new_frame(void) {
    if (!g_is_open || !g_display) return;
    
    // Pump all pending X events
    x11_pump_events();
    
    // Update delta time
    x11_timer_tick();
    
    // Bridge input to session
    if (g_x11_session) {
        kt_input_mouse_move(g_x11_session, g_mouse_x, g_mouse_y);
        for (int b = 0; b < 5; b++) {
            if (g_mouse_down[b]) kt_input_mouse_down(g_x11_session, b);
            else                 kt_input_mouse_up(g_x11_session, b);
        }
        if (g_scroll_dx != 0.0f || g_scroll_dy != 0.0f)
            kt_input_scroll(g_x11_session, g_scroll_dx, g_scroll_dy);
        for (int k = 0; k < 256; k++) {
            if (g_keys[k]) kt_input_key_down(g_x11_session, k);
            else           kt_input_key_up(g_x11_session, k);
        }
        if (g_text_len > 0) {
            kt_input_text(g_x11_session, g_text_buf);
        }
    }
    
    // Reset per-frame input
    g_scroll_dx = 0.0f; g_scroll_dy = 0.0f;
    g_text_len  = 0;
}
```

### 4.2 Event Pump

```c
static void x11_pump_events(void) {
    while (XPending(g_display)) {
        XEvent ev;
        XNextEvent(g_display, &ev);
        x11_handle_event(&ev);
    }
}
```

### 4.3 Event Router

```c
static void x11_handle_event(XEvent* ev) {
    switch (ev->type) {
    case ClientMessage:
        if ((Atom)ev->xclient.data.l[0] == g_wm_delete_window) {
            g_should_close = true;
        }
        break;
    case DestroyNotify:
        g_is_open = false;
        break;
    case ConfigureNotify:
        // Resize handling — see §3.5
        x11_handle_resize(ev->xconfigure.width, ev->xconfigure.height);
        break;
    case MotionNotify:
        g_mouse_x = (float)ev->xmotion.x / g_dpi_scale_x;
        g_mouse_y = (float)ev->xmotion.y / g_dpi_scale_y;
        break;
    case ButtonPress:
        x11_handle_button_press(&ev->xbutton);
        break;
    case ButtonRelease:
        x11_handle_button_release(&ev->xbutton);
        break;
    case KeyPress:
        x11_handle_key_press(&ev->xkey);
        break;
    case KeyRelease:
        x11_handle_key_release(&ev->xkey);
        break;
    case FocusIn:
        g_focus_gained = true;
        break;
    case FocusOut:
        g_focus_gained = false;
        memset(g_keys, 0, sizeof(g_keys));
        break;
    case Expose:
        // Repaint requested — handled by next render
        break;
    }
}
```

### 4.4 Input Translation

#### Mouse Buttons

| X11 Button | Kaintana Button |
|-----------|-----------------|
| Button1 (left) | 0 |
| Button2 (middle) | 2 |
| Button3 (right) | 1 |
| Button4 (scroll up) | → `g_scroll_dy += 1.0` |
| Button5 (scroll down) | → `g_scroll_dy -= 1.0` |
| Button6 (scroll left) | → `g_scroll_dx -= 1.0` |
| Button7 (scroll right) | → `g_scroll_dx += 1.0` |

```c
static void x11_handle_button_press(XButtonEvent* ev) {
    switch (ev->button) {
    case Button1: g_mouse_down[0] = true; break;
    case Button2: g_mouse_down[2] = true; break;
    case Button3: g_mouse_down[1] = true; break;
    case Button4: g_scroll_dy += 1.0f; break;
    case Button5: g_scroll_dy -= 1.0f; break;
    case Button6: g_scroll_dx -= 1.0f; break;
    case Button7: g_scroll_dx += 1.0f; break;
    }
}
```

#### Keyboard — KeySym to scancode mapping

X11 uses `KeySym` values, not scancodes. Need a mapping table (X11 keysym → Kaintana key index).

```c
static int x11_keysym_to_kain(KeySym ks) {
    // ASCII range
    if (ks >= XK_space && ks <= XK_asciitilde)
        return (int)ks;  // Direct ASCII mapping
    // Special keys
    switch (ks) {
    case XK_Return: case XK_KP_Enter:  return 13;  // VK_RETURN
    case XK_Tab:                        return 9;   // VK_TAB
    case XK_BackSpace:                  return 8;   // VK_BACK
    case XK_Escape:                     return 27;  // VK_ESCAPE
    case XK_Left:                       return 37;  // VK_LEFT
    case XK_Up:                         return 38;  // VK_UP
    case XK_Right:                      return 39;  // VK_RIGHT
    case XK_Down:                       return 40;  // VK_DOWN
    case XK_Shift_L: case XK_Shift_R:   return 16;  // VK_SHIFT
    case XK_Control_L: case XK_Control_R: return 17; // VK_CONTROL
    case XK_Alt_L: case XK_Alt_R:       return 18;  // VK_MENU
    case XK_Super_L: case XK_Super_R:   return 91;  // VK_LWIN
    case XK_Delete:                     return 46;  // VK_DELETE
    case XK_Home:                       return 36;  // VK_HOME
    case XK_End:                        return 35;  // VK_END
    case XK_Page_Up:                    return 33;  // VK_PRIOR
    case XK_Page_Down:                  return 34;  // VK_NEXT
    case XK_Insert:                     return 45;  // VK_INSERT
    case XK_F1: case XK_F2: case XK_F3: case XK_F4:
    case XK_F5: case XK_F6: case XK_F7: case XK_F8:
    case XK_F9: case XK_F10: case XK_F11: case XK_F12:
        return 112 + (ks - XK_F1);  // VK_F1 = 112
    default: return 0;
    }
}
```

#### KeyPress → Text Input

```c
static void x11_handle_key_press(XKeyEvent* ev) {
    // Set key state
    KeySym ks = XLookupKeysym(ev, 0);
    int kc = x11_keysym_to_kain(ks);
    if (kc > 0 && kc < 256) g_keys[kc] = true;
    
    // Text input — use XLookupString for ASCII, Xutf8LookupString for UTF-8 (Xutf8TextPropertyToTextList)
    char buf[8] = {0};
    int len = XLookupString(ev, buf, sizeof(buf), &ks, NULL);
    if (len > 0 && g_text_len + len < 32) {
        // Skip control characters
        for (int i = 0; i < len; i++) {
            if (buf[i] >= 32) {
                g_text_buf[g_text_len++] = buf[i];
            }
        }
        g_text_buf[g_text_len] = '\0';
    }
}
```

## 5. Framebuffer (Software Rendering)

### 5.1 XImage Creation

```c
static int x11_fb_create(int width, int height) {
    if (width <= 0 || height <= 0) return -1;
    
    // Allocate pixel buffer
    g_fb_width  = width;
    g_fb_height = height;
    g_fb_stride = width * 4;  // 32bpp
    
    g_pixels = (uint32_t*)calloc(1, (size_t)(g_fb_stride * height));
    if (!g_pixels) return -1;
    
    // Create XImage wrapping the buffer
    // Note: X11 uses 32-bit depth with byte order = LSBFirst (little-endian)
    // Pixel format: 0xAARRGGBB (same as Win32 DIB)
    g_ximage = XCreateImage(g_display, DefaultVisual(g_display, g_screen),
        DefaultDepth(g_display, g_screen), ZPixmap, 0,
        (char*)g_pixels, width, height, 32, g_fb_stride);
    
    if (!g_ximage) {
        free(g_pixels);
        g_pixels = NULL;
        return -1;
    }
    
    // XCreateImage's `data` field is used by XPutImage — it must point to
    // our buffer. XCreateImage allocated its own; replace it.
    // NOTE: XDestroyImage will NOT free our buffer — we must free g_pixels separately.
    free(g_ximage->data);
    g_ximage->data = (char*)g_pixels;
    g_ximage->bytes_per_line = g_fb_stride;
    
    return 0;
}
```

**Critical design note:** XImage's `data` pointer is what `XPutImage` reads from. We set it to our own `g_pixels` buffer. We must free `g_pixels` manually — `XDestroyImage` only frees the XImage struct, not the pixel data. This is different from CreateDIBSection where GDI manages the memory.

### 5.2 Present (XPutImage)

```c
static void x11_present_to_screen(void) {
    if (!g_display || !g_window || !g_ximage) return;
    
    // Full-screen putimage
    XPutImage(g_display, g_window, g_gc, g_ximage,
        0, 0,                              // source x, y
        0, 0,                              // dest x, y
        g_fb_width, g_fb_height);          // width, height
    
    XFlush(g_display);
}
```

### 5.3 Pixel Fill Functions

Same dual-pixel fill pattern as `host_win32.c`:

```c
static inline uint32_t x11_blend_pixel(uint32_t src, uint32_t dst) {
    // Identical to win32_blend_pixel — premultiplied SrcOver
    uint32_t sa = (src >> 24) & 0xFF;
    if (sa == 0) return dst;
    if (sa == 255) return src;
    uint32_t inv_a = 255 - sa;
    uint32_t rb = ((dst & 0x00FF00FF) * inv_a);
    uint32_t g  = ((dst & 0x0000FF00) * inv_a);
    uint32_t out_rb = (src & 0x00FF00FF) + kaintana__DIV255(rb);
    uint32_t out_g  = (src & 0x0000FF00) + kaintana__DIV255(g);
    return (out_rb & 0x00FF00FF) | (out_g & 0x0000FF00)
         | (0xFF000000 & ~(inv_a << 24));
}
```

## 6. DPI Detection

### 6.1 Detection Chain

```c
static void x11_detect_dpi(void) {
    float dpi = 96.0f;  // Default
    
    // Method 1: Xft.dpi via X resources (most common)
    XrmInitialize();
    char* rdb = XResourceManagerString(g_display);
    if (rdb) {
        XrmDatabase db = XrmGetStringDatabase(rdb);
        XrmValue value;
        char* type;
        if (XrmGetResource(db, "Xft.dpi", "Xft.dpi", &type, &value)) {
            dpi = (float)atof(value.addr);
        }
        XrmDestroyDatabase(db);
    }
    
    // Method 2: GDK_SCALE env var
    if (dpi <= 0) {
        const char* gdk = getenv("GDK_SCALE");
        if (gdk) dpi = (float)atoi(gdk) * 96.0f;
    }
    
    // Method 3: QT_SCALE_FACTOR env var
    if (dpi <= 0) {
        const char* qt = getenv("QT_SCALE_FACTOR");
        if (qt) dpi = (float)atof(qt) * 96.0f;
    }
    
    // Method 4: xdpyinfo-based fallback (DisplayWidthMM)
    if (dpi <= 0) {
        int w_pix = DisplayWidth(g_display, g_screen);
        int w_mm  = DisplayWidthMM(g_display, g_screen);
        if (w_mm > 0) {
            dpi = (float)w_pix / ((float)w_mm / 25.4f);
        }
    }
    
    // Clamp and set
    if (dpi < 72.0f)  dpi = 72.0f;
    if (dpi > 384.0f) dpi = 384.0f;
    
    g_dpi_scale_x = dpi / 96.0f;
    g_dpi_scale_y = dpi / 96.0f;
}
```

**Priority order:**

1. `Xft.dpi` from X resources (XResourceManagerString) — user's font DPI setting, most reliable
2. `GDK_SCALE` env var (integer) — GTK apps use this
3. `QT_SCALE_FACTOR` env var (fractional) — Qt apps use this
4. `DisplayWidthMM` back-calculation — unreliable fallback
5. Default 96 DPI (all detection failed)

## 8. Render (kt_DrawData → X11 pixels)

```c
static void x11_render(const kt_DrawData* draw_data) {
    if (!g_pixels || !g_ximage) return;
    if (!draw_data || !draw_data->cmds || draw_data->cmd_count <= 0) return;
    
    // Clear framebuffer
    memset(g_pixels, 0, (size_t)(g_fb_width * g_fb_height * 4));
    
    // Process commands
    for (int i = 0; i < draw_data->cmd_count; i++) {
        const kt_Cmd* cmd = &draw_data->cmds[i];
        switch (cmd->type) {
        case KT_CMD_FILL:
            if (cmd->radius > 0.5f)
                x11_fb_fill_rounded_rect(...);
            else
                x11_fb_fill_rect(...);
            break;
        case KT_CMD_STROKE:
            // 4 thin rects (top, bottom, left, right) — same as Win32
            break;
        case KT_CMD_CLIP:
            // Track clip rect; apply in pixel fills
            break;
        case KT_CMD_UNCLIP:
            // Restore clip
            break;
        case KT_CMD_TEXT:
            // Text rendering via XDrawString or Xft
            break;
        case KT_CMD_IMAGE:
            // Placeholder
            break;
        }
    }
    
    // Present to screen
    x11_present_to_screen();
}
```

## 9. Lifecycle

### 9.1 `x11_init`

```c
static int x11_init(const KaintanaBackendConfig* config) {
    if (!config) return -1;
    g_x11_session = (kt_Session*)config->platform_handle;
    
    if (x11_open_display() != 0) return -1;
    x11_detect_dpi();
    
    if (g_x11_session)
        kt_set_native_scale(g_x11_session, g_dpi_scale_x, g_dpi_scale_y);
    
    if (x11_create_window(config) != 0) {
        XCloseDisplay(g_display);
        g_display = NULL;
        return -1;
    }
    
    // Create framebuffer
    int fb_w = (int)((float)g_win_width * g_dpi_scale_x);
    int fb_h = (int)((float)g_win_height * g_dpi_scale_y);
    x11_fb_create(fb_w, fb_h);
    
    x11_timer_init();
    return 0;
}
```

### 9.2 `x11_shutdown`

```c
static void x11_shutdown(void) {
    if (g_ximage) {
        g_ximage->data = NULL;  // Prevent XDestroyImage from freeing our buffer
        XDestroyImage(g_ximage);
        g_ximage = NULL;
    }
    free(g_pixels);
    g_pixels = NULL;
    
    if (g_gc)       XFreeGC(g_display, g_gc);
    if (g_window)   XDestroyWindow(g_display, g_window);
    if (g_display)  XCloseDisplay(g_display);
    
    g_display = NULL;
    g_window  = 0;
    g_is_open = false;
}
```

## 12. Testing Strategy

### 12.1 Null Backend Equivalence

The X11 backend's render path (fill rect, SDF rounded rect, stroke) is pixel-identical to the Win32 backend — same `g_pixels` array, same `kaintana__DIV255` blend, same Premultiplied SrcOver. Unit tests can compare output.

### 12.2 Headless Testing

Using `Xvfb` (X Virtual Framebuffer):

```bash
Xvfb :99 -screen 0 1280x720x24 &
DISPLAY=:99 ./my_kaintana_app
```

Or using the null backend for CI:

```c
// CI build links only host_null.c, not host_x11.c
kt_backend_register(s, "null", &kaintana_null_backend);
kt_backend_select(s, "null");
```

### 12.3 Cross-Backend Pixel Diff

Same `kt_DrawData` → different backends should produce identical pixel buffers:

```c
// After rendering with X11 backend
uint32_t* x11_pixels = g_pixels;

// After rendering with null backend
uint32_t* null_pixels = kaintana_null_fb;

// Assert pixel equality
for (int i = 0; i < fb_w * fb_h; i++)
    assert(x11_pixels[i] == null_pixels[i]);
```

## 13. Risks

| # | Risk | Likelihood | Impact | Mitigation |
|---|------|-----------|--------|------------|
| 1 | **Xlib vs XCB** — Xlib is deprecated, XCB is modern. | Low | Medium | Start with Xlib. XCB migration is a texture replacement (XCB provides same protocol, different C API). Both speak same X11 protocol. |
| 2 | **No compositor = no transparency** — X11 doesn't require a compositor. Alpha blending needs the compositor (or we do it entirely in software). | Low | Low | We already do all alpha blending in software framebuffer. The XImage is fully composited before XPutImage. No compositor dependency. |
| 3 | **No DPI change events** — X11 has no `WM_DPICHANGED` equivalent. | Medium | Low | Poll DPI on user request (e.g., hotkey) or check on resize. Or re-read Xresources periodically. |
| 4 | **XIM vs XKB for keyboard** — Modern X11 uses XKB, but XIM is still used for IME. | Low | Medium | Use `XkbKeycodeToKeysym` for key mapping, `Xutf8LookupString` for text. Can drop XIM entirely for P0. |
| 5 | **Xft font fallback** — Complex CJK/Arabic text needs fontconfig. | Medium | Low | P0: `XDrawString` for ASCII. P1: `Xft` + `fontconfig`. CJK is deferred. |
| 6 | **Remote X11** — Over-the-network rendering may have latency. | Low | Low | XPutImage over SSH X-forwarding works but is slow. Not a P0 concern. |
| 7 | **`WIN32_DIRTY_RECT_MAX` equivalent** — X11 has no built-in damage rect accumulation. | Low | Low | Damage rect tracking is done in software (same as Win32) and consumed by `XPutImage` which copies the full buffer anyway. Dirty rect optimization is deferred to P1. |
| 8 | **Ancient API surface** — X11 API is 40+ years old. Undocumented behaviors around `XPutImage` and `ZPixmap`. | Low | Low | All pixel operations are in our buffer. XPutImage is simple: a memcpy to the server. |
