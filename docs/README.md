## Current Layout

- `archive/` holds retired or historical material.
- `automation/` holds agent handoff and automation notes.
- `crates/` holds crate-focused documentation.
- `guides/` holds longer-form reference material.
- `kainplan/` holds active design, requirements, and task docs.
- `kainvsgiants/` holds strategic positioning notes.
- `pipeline/` holds pipeline navigation and operational notes.
- `recent/` holds fresh validation logs and recent work notes.
- `stdlib/` holds standard-library references.
- `validation/` holds validation reports and logs.

## Rule

Prefer a folder README before adding more standalone docs to a directory that already has a stable namespace.
