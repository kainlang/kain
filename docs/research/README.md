# Research Notes

This folder holds exploratory research and reverse-engineering work that is still relevant but does not belong in active pipeline or design docs.

## Keep Here

- reverse engineering notes (chipsets, consoles, retro formats)
- target-specific investigations that inform compiler or runtime work
- experimental findings that may feed future pipeline docs

## Move Out

- once a research thread becomes a concrete plan, promote it to `docs/kainplan/`
- once it becomes stable guidance, move it to `docs/guides/`
- if it is obsolete, archive it under `docs/archive/`
