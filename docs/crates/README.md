# Docs Crates Index

This folder collects crate-focused documentation that belongs to the docs layer instead of the source tree.

Use it for crate navigation notes, migration writeups, audit summaries that are still useful, and guidance that should sit near the workspace documentation rather than the implementation itself.

## Rule

If the note is only useful until the next tree reshape, keep it short and promote the surviving truth into the crate guide or repo map instead of letting it linger as a standalone audit dump.
