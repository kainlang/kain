# Project

Project scaffolding and file management for the reson8 DAW.
Create new projects, scan for existing ones, and manage the
project lifecycle through markscript orchestration.

Run with: `kain run reson8 -- --mks src-mks/project.md`

---

## ProjectLayout

The canonical directory structure for a reson8 project. Every
new project is scaffolded from this template.

| Path                        | Purpose                              |
|-----------------------------|--------------------------------------|
| project.reson8              | Project manifest (Kain TOML)         |
| audio/                      | Rendered audio + frozen tracks       |
| midi/                       | Exported MIDI files                  |
| stems/                      | Per-track stem exports               |
| automation/                 | Automation lane snapshots            |
| plugins/                    | Project-local plugin state           |
| undo/                       | Patch journal + undo history         |
| sessions/                   | Named session snapshots              |
| backups/                    | Time-stamped project backups         |
| .meta/                      | Project metadata + cache             |

---

## ProjectFileTemplate

The `project.reson8` manifest format. Auto-generated by `new_project`.

| Field        | Default            | Description                        |
|--------------|--------------------|------------------------------------|
| name         | my_project         | Project display name               |
| version      | 0.1.0              | Semver project version             |
| created      | 2026-06-20         | ISO 8601 creation date             |
| sample_rate  | 48000              | Hz                                 |
| tempo        | 120                | BPM                                |
| time_sig     | 4/4                | Time signature                     |
| key          | C                  | Musical key                        |
| length_bars  | 64                 | Default session length in bars     |
| tracks       | 8                  | Number of tracks to scaffold       |

## new_project

Create a new project directory with the canonical layout, manifest
file, and default track scaffold. Project name becomes the
directory name and is used as the default project name.

> mkdir "projects/my_project"

> mkdir "projects/my_project/audio"

> mkdir "projects/my_project/midi"

> mkdir "projects/my_project/stems"

> mkdir "projects/my_project/automation"

> mkdir "projects/my_project/plugins"

> mkdir "projects/my_project/undo"

> mkdir "projects/my_project/sessions"

> mkdir "projects/my_project/backups"

> touch "projects/my_project/project.reson8"

> print "New project created: projects/my_project"

---

## new_project_named

Scaffold a project with a custom name. The first argument is the
project directory name; all subdirectories derive from it.

```markscript
let name = "my_album_2026"
print(name)
```

> mkdir "projects/" + "my_album_2026"

> mkdir "projects/my_album_2026/audio"

> mkdir "projects/my_album_2026/midi"

> mkdir "projects/my_album_2026/stems"

> mkdir "projects/my_album_2026/automation"

> mkdir "projects/my_album_2026/plugins"

> mkdir "projects/my_album_2026/undo"

> mkdir "projects/my_album_2026/sessions"

> mkdir "projects/my_album_2026/backups"

> touch "projects/my_album_2026/project.reson8"

> print "Project scaffolded: my_album_2026"

## list_projects

Scan the projects directory and list all valid reson8 projects.
A valid project has a `project.reson8` manifest file at its root.

> readdir "projects/"

> print "Projects directory scanned"

---

## project_exists

Check whether a named project exists. Returns 1 if the project
directory and manifest are both present, 0 otherwise.

```markscript
let manifest = "projects/my_project/project.reson8"
let result = exists(manifest)
print(result)
```

> exists "projects/my_project/project.reson8"

---

## open_project

Open an existing project by loading its manifest and initializing
the four world blocks from the saved state.

> print "Opening project: my_project"

> read "projects/my_project/project.reson8"

> spawn "kain run reson8 -- --load-project projects/my_project"

> print "Project loaded"

---

## save_project

Save current session state to the project file. Patches the four
world blocks and writes a new manifest revision.

> print "Saving project state"

> spawn "kain run reson8 -- --save-project projects/my_project"

> print "Project saved"

---

## backup_project

Create a time-stamped backup of the entire project directory.
Backups go into the project's `backups/` folder.

> print "Creating backup..."

> spawn "kain run reson8 -- --backup projects/my_project"

> sleep 500

> print "Backup complete"

---

## restore_project

Restore a project from a named backup. The backup name is the
time-stamped directory under `backups/`.

> print "Restoring from backup..."

> spawn "kain run reson8 -- --restore projects/my_project backups/2026-06-20_143022"

> print "Restore complete"

---

## close_project

Close the current project, flush all world state to the manifest,
and free per-project resources.

> print "Closing project"

> spawn "kain run reson8 -- --close-project"

> print "Project closed"

---

## delete_project

Remove a project directory and all its contents. This is a
destructive operation — the project is archived to `backups/`
before deletion so it can be recovered.

> print "Archiving project before deletion..."

> run backup_project

> print "Deleting project directory..."

> spawn "kain run reson8 -- --delete-project projects/my_project"

> print "Project deleted (recoverable from backups/)"

---

## rename_project

Rename a project. Updates the directory name and the `name` field
in the project manifest. All internal paths are relative, so no
other rewrites are needed.

> print "Renaming project..."

> spawn "kain run reson8 -- --rename-project projects/my_project projects/renamed_project"

> print "Project renamed"

---

## clone_project

Duplicate a project. The clone gets a new directory and a fresh
project version (patch number incremented). Original is untouched.

> print "Cloning project..."

> spawn "kain run reson8 -- --clone-project projects/my_project projects/my_project_v2"

> print "Project cloned"

---

## import_project

Import a project from an external archive (`.reson8` file).
Extracts to a new directory in `projects/` and loads it.

> print "Importing project archive..."

> spawn "kain run reson8 -- --import-project backup.reson8 projects/imported_project"

> print "Project imported"

---

## export_project_archive

Bundle a project into a portable `.reson8` archive. Contains all
audio, MIDI, plugin state, and undo history in a single file.

> spawn "kain run reson8 -- --export-project projects/my_project my_project.reson8"

> print "Project archive created: my_project.reson8"

---

## list_sessions

List all named session snapshots within a project. Sessions
are restore points that include full state and undo history.

> readdir "projects/my_project/sessions/"

> print "Sessions listed"

---

## save_session

Save a named session snapshot. The session name becomes the
filename under `sessions/`.

> print "Saving session..."

> spawn "kain run reson8 -- --save-session projects/my_project \"Mix v3 pre-master\""

> print "Session saved"

---

## load_session

Restore a named session snapshot. Reverts all world state to
the saved point and clears the current undo history.

> print "Loading session..."

> spawn "kain run reson8 -- --load-session projects/my_project \"Mix v3 pre-master\""

> print "Session loaded"

---

## clean_temp

Remove temporary files and caches from a project. Does not
touch the manifest, audio, or session data.

> print "Cleaning project temporary files..."

> spawn "kain run reson8 -- --clean-temp projects/my_project"

> print "Temp files cleaned"

## Project Lifecycle Graph

| Phase         | Routine             | Output                          |
|---------------|---------------------|---------------------------------|
| create        | new_project         | scaffolded directory            |
| open          | open_project        | loaded world state              |
| edit          | (interactive)       | patched world state             |
| save          | save_project        | updated manifest                |
| snapshot      | save_session        | named restore point             |
| backup        | backup_project      | time-stamped archive            |
| export        | export_project_archive | .reson8 portable file        |
| close         | close_project       | flushed + freed resources       |
| delete        | delete_project      | archived then removed           |
