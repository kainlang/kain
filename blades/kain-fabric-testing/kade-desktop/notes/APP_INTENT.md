# Kade Desktop App Intent

## Product Shape

Native desktop agent shell for chat, tool execution, workspace browsing, provider switching, MCP integration, and multi-agent orchestration.

## Runtime Priorities

1. Stable bundle-only native app materialization.
2. Host-backed file, process, and API service contracts.
3. Chat/session persistence that survives restarts.
4. Data-driven command, provider, panel, and tool manifests.

## Near-Term Goal

Stand up a credible desktop shell that mirrors the Kade product architecture without depending on the VS Code extension host.
