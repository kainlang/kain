# UI-Template - Markscript Build Orchestrator

> Kicks off the full Kain build pipeline for the hex color mixer UI template.
> Every domain is a build stage. Every operation is an intent.
> No Makefile. No shell script. No JSON config. The markdown IS the build.

---

## Metadata

| Property | Value |
|----------|-------|
| Project | ui-template |
| Version | 0.1.0 |
| Entry | src/main.kn |
| Target | llvm |
| Profile | debug |
| Runtime | kain run --target llvm |

---

## StageCheck - Typecheck the project

> Fast path: verify all .kn files typecheck before codegen.

```markscript
print("=== UI-TEMPLATE BUILD ORCHESTRATOR ===")
print("")
print("Stage 1: Typecheck")
```

> run "kain check src/"

> print "Typecheck complete"

---

## StageBuild - Compile to native

> Full LLVM codegen path: .kn → .ll → clang → .exe

```markscript
print("")
print("Stage 2: Compile to native")
```

> run "kain build src/ --target llvm"

> print "Build complete"

---

## StageVerify - Assert artifacts exist

> Confirm the native executable was produced.

```markscript
print("")
print("Stage 3: Verify artifacts")
```

> print "Checking for output binary..."

> file exists ".kain/out"

> print "Output directory confirmed"

---

## StageRun --- Execute the UI

> Launch the hex color mixer. This is the real thing.

```markscript
print("")
print("Stage 4: Run")
print("Launching hex color mixer UI...")
print("(close the window to continue)")
```

> run "kain run src/main.kn --target llvm"

> print "UI session ended"

---

## StageReport -- Final summary

```markscript
print("")
print("=== BUILD PIPELINE COMPLETE ===")
print("Project:  ui-template")
print("Stages:   4 (check → build → verify → run)")

```

---

## Pipeline Map

| Stage | Domain | Intents | Purpose |
|-------|--------|---------|---------|
| 1 | StageCheck | run, print | Typecheck all sources |
| 2 | StageBuild | run, print | LLVM codegen → native |
| 3 | StageVerify | file exists, print | Confirm output artifacts |
| 4 | StageRun | run, print | Execute the UI |
| 5 | StageReport | print | Summary and next steps |

> All 5 stages run in a single Markscript VM session.
> The markdown documents the build AND executes it.
> This file is both the README and the build script.
