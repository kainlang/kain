# Apps

`apps/` holds first-class applications and app prototypes that exercise the full
Kain stack.

## Key Apps

| App | What It Proves |
| --- | --- |
| `kade-desktop/` | Native desktop app lane and supporting assets |
| `kain-canvas-forge/` | Node-first painting and Three.js composition studio path |
| `kain-fabric-modeler/` | Fabric-first native 3D modeling workbench |
| `kain-fabric-dcc-suite/` | Broader Fabric-first DCC suite scaffold |
| `3D/` | 3D app and tooling lane |
| `ZenDAW/` | Audio/workstation-oriented app lane |

## Output Hygiene

App build outputs are disposable. Keep generated executables, caches, and local
preview folders out of git.

## Read This As A Workflow

These folders are not examples in the tutorial sense only. They are active app
prototypes that prove how Kain behaves as a product substrate.
