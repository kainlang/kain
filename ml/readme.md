## ML
This folder is for gathering every kain example throughout the repo etc - just run the lasso.kn script and then processor to gather everything.

THE_MESSIAH.KN is a built in commited file in case anyone wants to gather training data or train a model on kain -- the processor script can convert the messiah into a jsonl if need be

THE_MESSIAH is over 6000 concatenated files and over 800,000 lines of kain code so its a great thing to have around as reference or if you want to rg it for reference.
