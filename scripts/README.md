# Kain Scripts Folder Guide

This folder stores operational scripts for building, validating, or maintaining the Kain workspace.

## What Lives Here

- build and sync scripts (`*.ps1`, `*.bat`, `*.sh`)
- helper utilities for audits or data extraction
- `DIRECTORY.md` as the detailed script index

## Notes

- keep scripts data-driven and avoid hardcoded absolute paths when possible
- document new scripts inside `DIRECTORY.md`
